Help / Getting Started

The V7 daily workflow in plain language

Daily workflow

Sale: Sales → New Sale → customer → items → payment → Save. Customer, invoice, stock and payment update together.

Purchase: Purchases → New Purchase → vendor → items → payment → Save. Vendor, stock and payable update together.

Quote: Sales → New Quote. Quotes do not change stock or payments until Convert to Sale.

Useful shortcuts

Ctrl/Cmd + N opens New Sale while on the Sales page.

On iPad, use the Menu button. Daily forms use large touch targets and sticky Save actions.

Corrections

Use Return Item for sold goods. A return creates a credit note first; cash refund is recorded only after money actually moves.

Final documents stay in history. Unpaid unlinked invoices/purchases can be voided; linked financial records protect them.

Backups and cloud setup

Settings → Download Backup. Restore validates the file and downloads a safety backup before replacement.

Every administrator session loads the business from Firestore. Saves update linked business records together, and stale device copies must reload before saving.
