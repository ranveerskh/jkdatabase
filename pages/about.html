Application architecture

Pages → services → repository → validated local recovery cache and business-scoped Firestore records. Transaction logic stays separate from authentication and cloud persistence.

Cloud access

Firebase Authentication signs administrators in. Firestore Security Rules verify the business membership on every cloud read and write. Other roles can be added through a controlled permission design in a later release.
